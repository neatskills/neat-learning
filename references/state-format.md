# State File Format

**Location:** `docs/neat_learning/<topic>/map.md`

**Format:** YAML frontmatter (all state) + Markdown body (human-readable map)

Read and write via `scripts/state-manager.js` (`loadState`, `saveState`). Record
activity results via `scripts/activity-updater.js` rather than hand-editing fields.

## Markdown Body

Human-readable summary generated by `scripts/init-map.js` (map overview, concept
list, review schedule). The frontmatter is the source of truth; regenerate or
update the body when presenting, never parse state from it.

## Field Types

- Dates: ISO 8601 strings (`2026-06-27T00:00:00.000Z`)
- `review_interval`: Seconds as integer (e.g. `172800` = 2 days) - only set once mastered
- `last_activity`: ISO date of the latest activity or review - basis for review due calculation
- `status`: Enum `[not-started, learning, practicing, mastered]` (see SKILL.md Concept Status Values)
- `coverage`: Optional Learn field tracking which core/depth/breadth topics were covered
- `exam_blueprint`: Optional - present only on exam-mode maps (see `references/exam-mode.md`).
  `source` is `official` or `ai-estimated`; `source_url` present only when `source: official`
