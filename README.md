# Neat Learning

AI-guided discovery-based learning system. Build customized learning maps, track progress across sessions, prevent forgetting with spaced repetition.

## Features

- **5 Learning Activities:** Explore → Discover → Name → Practice → Calibrate
- **4 Domain Support:** Technical, soft skills, business, theoretical
- **Spaced Repetition:** 2-60 day intervals based on performance
- **Multi-session State:** YAML frontmatter + Markdown
- **Progress Tracking:** Mastery levels 0-7, concept dependencies
- **Compression Checkpoints:** Archive mastered concepts to keep maps focused

## Quick Start

```bash
# In Claude Code
/neat-learning
```

Then: "Teach me [topic]"
